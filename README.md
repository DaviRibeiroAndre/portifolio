# Portfólio de Davi Ribeiro André

Portfólio acadêmico em HTML semântico, CSS e JavaScript para o carrossel. Tema escuro inspirado em colmeias, com classes em português e código sem comentários.

## Organização

- index.html: conteúdo e estrutura da página.
- assets/css/base.css: estilos estruturais e responsividade.
- assets/css/tema.css: tema atual, componentes e ajustes visuais.
- assets/js/carrossel.js: navegação dos projetos pessoais.

## Visualizar e publicar

Abra index.html no navegador. Para GitHub Pages, publique a raiz da branch escolhida em Settings > Pages.

Foto, imagens provisórias, fontes, ícones e bandeiras utilizam serviços externos e precisam de internet. Ícones: https://github.com/primer/octicons (MIT). As imagens aleatórias dos projetos devem ser substituídas por capturas reais.
